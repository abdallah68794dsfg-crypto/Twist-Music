# Twist Music

تطبيق Android بواجهة عربية باسم Twist Music.

- اسم التطبيق: Twist Music
- المطور: @Mando_js
- قناة المطور: https://t.me/freeMohamedNet
- Android applicationId: com.mando.twistmusic

## الوظائف الموجودة
- تسجيل الدخول برقم الهاتف ورمز التحقق.
- حفظ الجلسة محلياً داخل مساحة التطبيق الخاصة واستعادتها عند فتحه.
- عرض وتحديث رصيد الكوينز.
- تنفيذ مهام الشارات والمكافآت المرتبطة بمراحل التقدم.
- عرض باقات الوحدات السبع مع التحقق من الرصيد والحد الشهري.
- تأكيد عملية الاستبدال قبل إرسال الطلب.
- تنفيذ تجميع المهام ثم محاولة السحب من خلال خيار واحد.
- أيقونة تشغيل خاصة بتصميم Twist Music.

## البناء
افتح المشروع في Android Studio مع JDK 17 ثم نفّذ:
`gradle assembleDebug`

يمكن أيضاً تشغيل GitHub Actions من تبويب Actions لبناء APK وإرفاقه كـ Artifact.

## ملاحظات مهمة
يتصل التطبيق بنقاط API الخاصة بخدمة Twist غير موثقة رسمياً؛ الاسم الظاهر Twist Music ولا يغيّر مزود الخدمة أو وظائفه؛ قد تتغير أو ترفض الطلبات في أي وقت. حفظ الجلسة محلي داخل مساحة التطبيق الخاصة، لذلك لا تشارك جهازك أو رموز الجلسة. عمليات تنفيذ المهام والاستبدال يقررها الخادم؛ ظهور رسالة نجاح الطلب لا يضمن أن مزود الخدمة منح المكافأة أو أضاف الوحدات. تحقق دائماً من الرصيد داخل حسابك الرسمي.
