# Twist Music

تطبيق Android بواجهة عربية لإدارة حساب Twist.

- اسم التطبيق: Twist Music
- المطور: @Mando_js
- قناة المطور: https://t.me/freeMohamedNet
- Android applicationId: com.mando.twistmusic

## البناء
افتح المشروع في Android Studio مع JDK 17 ثم نفّذ:
`gradle assembleDebug`

يمكن أيضاً تشغيل GitHub Actions من تبويب Actions لبناء APK وإرفاقه كـ Artifact.

## ملاحظات مهمة
يتصل التطبيق بنقاط API غير موثقة رسمياً مأخوذة من البرنامج الأصلي؛ قد تتغير أو ترفض الطلبات في أي وقت. لا تشارك رموز الجلسة أو بيانات تسجيل الدخول. عمليات تنفيذ المهام والاستبدال يقررها الخادم، ولا نضمن قبولها.
